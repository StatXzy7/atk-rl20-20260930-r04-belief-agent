# 有限预算信息获取 Agent（精确贝叶斯规划）

在有限预算下选择工具调用序列以最大化"最终答对概率 − κ×总成本"。
所有规划与估值均用 `fractions.Fraction` 精确有理数完成：任何输出数值
都可由输入完全复算，不依赖浮点舍入。不调用任何外部语言模型或工具服务。

## 运行

```bash
python3 -m pytest tests/ -q     # 49 个测试
python3 demo.py                 # 打印全部可核算的期望收益与对照
```

仅依赖 Python 标准库（3.11+）。

## 1. 问题形式化

- 隐藏变量 `z ∈ Z`（有限集），先验 `b₀(z)` 已知。
- 工具 `a ∈ A`：正整数成本 `c_a ≥ 1`，有限输出集 `O_a`，已知似然 `P(o|z,a)`。
- 给定 `z` 与所选工具，各次调用的输出条件独立。
- 每步：调用一个预算足够的工具（`c_a ≤ B`），或停止并报告 `ẑ`。
- 收益：`1[ẑ = z] − κ·Σc_a`，`κ ≥ 0`，剩余预算不得为负。
- 状态：`(b, B)` =（后验信念，剩余预算）。策略只能依赖该状态，
  隐藏真值 `z` 从不提供给策略（采样器中 `z` 只用于产生观测）。

## 2. 推导

### 2.1 贝叶斯更新

调用工具 `a` 得到观测 `o` 后，由条件独立性：

```
P(o|b,a)   = Σ_z b(z)·P(o|z,a)
b^{a,o}(z) = b(z)·P(o|z,a) / P(o|b,a)        （要求 P(o|b,a) > 0）
```

`P(o|b,a) = 0` 的观测以概率 0 出现，在期望递推中贡献为 0，直接跳过；
对其做条件化是未定义行为，`belief.update` 会显式抛错而不是静默产出
NaN。由于每个工具的似然行和为 1，任意信念下都有 `Σ_o P(o|b,a) = 1`，
至少一个输出概率为正，递推总能继续。

### 2.2 停止价值

停止时最优报告 `ẑ = argmax_z b(z)`，期望答对率即

```
V_stop(b) = max_z b(z)
```

平局按最低下标确定性地打破，保证策略可复现。

### 2.3 最优 Bellman 递推

```
V(b,B) = max( V_stop(b),  max_{a : c_a ≤ B} Q(b,B,a) )
Q(b,B,a) = −κ·c_a + Σ_{o : P(o|b,a)>0} P(o|b,a)·V(b^{a,o}, B−c_a)
```

良定义性：成本为正整数，每次递归使预算严格下降至少 1，深度 ≤ B，
无负环、无无限折扣需求；`B` 不足以支付任何工具时退化为 `V_stop(b)`。
从固定先验出发，可达信念只有有限个（受观测序列计数约束，见 §6），
故带备忘的递归在有限步内终止并给出精确最优值与策略。

动作平局规则：先 STOP，再按工具下标——确定性、可复现。

### 2.4 为什么不能用"最大信息增益"代替"最大决策收益"

目标泛函是 `E[max_z b'(z)] − κ·cost`（凸的决策价值），而信息增益
`H(b) − E[H(b')]` 衡量的是整个分布的熵减。二者对工具的排序可以相反
（§5.2 给出精确反例）：一个工具可以大幅削尾（熵减大）却不移动 MAP；
另一个工具熵减较小却更频繁地确认领先假设。规划器只优化决策价值，
`infogain.py` 仅用于构造对照。

## 3. 实现

| 模块 | 内容 |
| --- | --- |
| `budgeted_agent/model.py` | `Problem`/`Tool` 定义与校验（行和为 1、成本为正整数、κ≥0），JSON 往返 |
| `budgeted_agent/belief.py` | 精确贝叶斯更新、边际概率、停止价值、确定性 argmax |
| `budgeted_agent/planner.py` | `OptimalPlanner`（精确缓存的 Bellman 递归）；`RoundedCachePlanner`（**故意错误**的对照变体） |
| `budgeted_agent/baselines.py` | 立即停止、固定工具次序、单步贪心价值；任意无记忆策略的精确估值 |
| `budgeted_agent/enumeration.py` | 可达状态、全策略暴力枚举、按路径显式求和的独立估值 |

| `budgeted_agent/infogain.py` | 期望信息增益（仅对照用，浮点） |
| `budgeted_agent/trace.py` | 事件记录与 `replay`：由记录完全复算后验、成本、收益 |
| `budgeted_agent/examples.py` | 全部命名算例（精确分数常数） |

边界情形的处理：零概率观测跳过（§2.1）；退化先验下后验恒为退化分布，
最优即停止（`V=1`）；`B=0` 或工具全部超预算时 `V = V_stop`；确定性工具
（似然为 one-hot，含零概率项）自然支持。

## 4. 基线

1. **立即停止**：`V = max_z b₀(z)`。
2. **固定工具次序**：按给定顺序调用预算足够的工具（历史相关策略，
   用 `(位置, b, B)` 递归精确估值）。
3. **单步贪心价值**：每步选 `−κ·c_a + E[max_z b^{a,o}(z)]` 最大的动作，
   即"只往前看一步、假设调用后必须停止"的近视价值；其真实期望收益用
   精确递归另算（近视估值与真实值可不同）。

## 5. 失败反例（全部精确可核算）

### 5.1 单步贪心严格次优（`examples.complementary_bits`）

`Z={0,1,2,3}` 均匀先验，预算 2，κ=0：

- `pair_id`（成本 2）：精确识别 `z∈{0,1}`，把 `{2,3}` 合并为一个输出。
- `parity`、`high_bit`（各成本 1）：分别确定性地揭示 z 的低位、高位比特。

手算（`demo.py` 第 1 节复核）：

| 策略 | 精确值 |
| --- | --- |
| 立即停止 | 1/4 |
| 固定 [pair_id] | 1/4·1 + 1/4·1 + 1/2·1/2 = **3/4** |
| 单步贪心 | **3/4**（一步估值 3/4 > 1/2，选中 pair_id，预算耗尽） |
| 固定 [parity, high_bit] | **1** |
| **最优（parity→high_bit）** | **1** |

贪心只看一步：两个比特工具各自的单步价值都是 1/2 < 3/4，于是错过
"两个半信息合成全信息"的互补组合。κ=1/16 时间隔保持：最优 7/8 vs
贪心 5/8。暴力枚举全部 324 个确定性策略独立确认最大值为 1。

### 5.2 最大信息增益 ≠ 最大决策收益（`examples.eig_trap`）

先验 `(1/2, 1/8, 1/8, 1/8, 1/8)`，预算 1，κ=0：

- `tail_id`：`z=0` 时在 `{1..4}` 上均匀造假，否则报出 `z`。
  EIG = 1 bit；但后验恒为 `(1/2, 1/2, 0,0,0)` 形，期望 max 后验 = 1/2。
- `leader_test`：`P(yes|z=0)=9/10`，其余状态绝不触发。
  EIG ≈ 0.7583 bits；期望 max 后验 = 9/20·1 + 11/20·5/22 = **23/40**。

按 EIG 选 `tail_id`（1.0 > 0.7583），按决策价值选 `leader_test`
（23/40 > 1/2）。规划器选择后者，最优值 23/40。

### 5.3 浮点近似合并缓存会改变策略（`examples.rounding_trap_problem`）

对称二元信道（精度 3/4，成本 1，κ=1/10，预算 1）。对
`b₀ = P(z=0) ∈ [1/2, 3/4]`，`E[max 后验] ≡ 3/4`，故调用最优当且仅当
`3/4 − 1/10 > b₀`，即 `b₀ < 13/20`。

- `b₀ = 649/1000`：调用（13/20 > 649/1000）。
- `b₀ = 651/1000`：停止（651/1000 > 13/20）。

两者舍入到两位小数都是 `(0.65, 0.35)`：`RoundedCachePlanner` 把它们合并，
先缓存哪个就对另一个给出错误动作（测试两种查询顺序，各错一个）。
精确参考路径用 `Fraction` 元组做键，永不合并不同信念——**不得靠随意
四舍五入来"节省"缓存**。若工程上必须用浮点键，需要带利普希茨误差界
的容差聚类，而不是裸舍入。

## 6. 状态空间增长与缓存开销

设深度上界 `D = B`（最小成本 1），分支因子 `K = Σ_a |O_a|`：

- **观测树路径数**（无缓存的朴素展开）≈ `K^D`，指数增长。
- **可达不同信念数**：后验只依赖各 `(a,o)` 出现的次数（贝叶斯更新可交换），
  故 ≤ 计数向量数 `∏_a C(B/c_a + |O_a|, |O_a|)`——对固定工具集是 B 的
  多项式（次数 `Σ_a |O_a|`），缓存把排列合并掉（阶乘级压缩）。
- 缓存条目存 `(belief 元组, budget) → (value, action)`，内存与不同信念数
  成正比；`planner.stats()` 报告条目数与展开次数。

实测（`noisy_channel`，单工具双输出，成本 1）：

| 预算 B | 缓存状态数 | 树路径数 |
| --- | --- | --- |
| 2 | 6 | 7 |
| 3 | 10 | 15 |
| 4 | 15 | 31 |
| 5 | 21 | 63 |
| 6 | 28 | 127 |

双输出信道下不同后验只有 `k+1` 种（k 次调用），状态数多项式增长，
路径数 `2^B−1` 指数增长——缓存的收益随预算指数级放大；代价是哈希与
存储（此处可忽略）。注意该多项式界随 `Σ_a |O_a|` 指数化，工具多、输出
多时可到达信念仍然爆炸，精确规划只适用于小规模问题。

## 7. 工具相关后，(b, B) 为何不再充分

条件独立性一旦破坏，单次似然 `P(o|z,a)` 不再存在，只剩联合
`P(o₁..o_t|z)`：

1. **更新失效**：`b^{a,o}` 无法由 `(b, o, a)` 算出，需要整段历史。
2. **转移失效**：`P(o_{t+1}|历史)` 不由 `b` 决定。

`examples.correlation_demo()` 的精确算例：`z∈{0,1}`，先验 `(2/3, 1/3)`；
`o₁` 为纯噪声，`o₂ = z`（若 `o₁=0`）否则 `1−z`。两段历史
`h₀=(o₁=0)`、`h₁=(o₁=1)` 给出**完全相同**的信念 `(2/3, 1/3)`，但

```
P(o₂=0 | h₀) = 2/3   ≠   P(o₂=0 | h₁) = 1/3
```

同一 `(b, B)` 对应不同的转移分布与不同的后续价值，Bellman 递推的
马尔可夫性被破坏；按信念合并缓存会把未来不同的历史错误合并。充分
状态必须扩为完整观测历史（或联合充分统计量），状态数随之从"计数向量
多项式"退回"历史序列指数"，§6 的缓存压缩也不再成立。

## 8. 独立核验

- **全策略枚举**（`enumeration.enumerate_all_policies`）：在小观测树上
  枚举可达状态 DAG 上的全部确定性无记忆策略并逐个精确估值
  （`noisy_channel` 8 个、`complementary_bits` 324 个），最大值须等于
  规划器的 Bellman 值。
- **路径求和**（`policy_value_by_paths`）：对规划器给出的策略，沿全部
  根到叶路径显式累加 `路径概率 × (期望答对 − κ·已花成本)`，并断言概率
  和为 1；与 Bellman 值一致（不复用规划器代码）。
- **固定种子 Monte Carlo**：`seed=20260930, n=4000`，样本均值对照精确值
  （如 `noisy_channel` 最优 13/20=0.65，MC 0.6578±0.0068；固定次序
  11/20=0.55，MC 0.5502±0.0068），测试容差 5 倍标准误且种子固定故结果
  确定。
- **记录复算**：`trace.record_episode` 只记录问题规格、`(工具, 观测)`
  序列、报告值与真值；`replay` 从中重算每步后验、累计成本与收益，
  并对超预算或零概率观测报错。
